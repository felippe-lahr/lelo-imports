# Fotos das categorias de peças

Coloque aqui uma foto por categoria. Use exatamente estes nomes (minúsculos, sem acento):

| Categoria            | Nome do arquivo        |
|----------------------|------------------------|
| Motor                | `motor.jpg`            |
| Suspensão            | `suspensao.jpg`        |
| Injeção Eletrônica   | `injecao.jpg`          |
| Rodas                | `rodas.jpg`            |
| Câmbio               | `cambio.jpg`           |
| Embreagem            | `embreagem.jpg`        |
| Lanternas            | `lanternas.jpg`        |
| Retrovisores         | `retrovisores.jpg`     |

Formatos aceitos: `.jpg`, `.jpeg`, `.png` ou `.webp`.
Recomendado: imagens quadradas (ex.: 800x800) ou próximas disso — elas são
exibidas com recorte `cover` preenchendo o card.
