## Como adicionar as fotos que faltam

1. Coloque a imagem original (`.jpg`, `.png` ou `.webp`) nesta pasta.
2. Avise que eu otimizo para `.webp` (~800px), aplico no card e mantenho o
   efeito de mouse over.

Recomendado: imagens próximas de quadradas (ex.: 800x800 ou 928x1152) — elas
são exibidas com recorte `cover` preenchendo o card 1:1.
